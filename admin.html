⚠️ 「商户密钥」不提供输入框，也不允许存进数据库。
admin.html 是 GitHub Pages 上的公开静态页，写进前端或 settings 的明文密钥，任何拿到后台网址的人都能读走； dujiao-next 的签名 = HMAC-SHA256(商户密钥)，拿到密钥即可任意刷你的对方余额。 它只能放在 Supabase Edge Function 的 Secrets 里，由服务端签名，浏览器永远拿不到。配置方法见 README 第 3 步。
